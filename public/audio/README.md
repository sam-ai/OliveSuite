# OliveSuite TTS Audio

Place real generated TTS files in this folder:

- `odia-privacy-reply.mp3`
- `odia-rag-answer.mp3`

Recommended formats:

- MP3 for broad browser support.
- WAV for highest fidelity if file size is acceptable.
- OGG as an optional secondary source if you later add multi-source audio markup.

Keep transcripts in the React component aligned with the spoken audio for accessibility.
